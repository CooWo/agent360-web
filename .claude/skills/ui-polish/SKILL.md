# 화면 마감 점검 (Ubase Hub)

사용자가 반복해서 지적한 것: **"디테일이 계속 모자라다"** — 표가 좁아 옆이 비고, 숫자·증감이 붙어 읽기 어렵고,
라벨이 겹치고, 좁은 미리보기 폭에서만 보고 끝냈다. 화면을 바꾼 작업은 아래를 모두 통과해야 끝이다.

## 1. 두 폭에서 직접 본다 (필수)
- 미리보기 서버는 자동 새로고침이 없다 → 파이썬(뷰·서비스·차트)을 고쳤으면 `preview_stop` 후 `preview_start` 로 다시 띄운다.
- `resize_window` 로 **1600×1000**(사용자 실제 화면, AI 패널 열림)과 **1024×800** 두 번 스크린샷. 끝나면 `preset: desktop` 으로 되돌린다.
- 고친 부분을 `zoom` 으로 확대해서 본다. 전체 스크린샷만 보고 넘어가지 않는다.
- 숫자·라벨은 `javascript_tool` 로 실제 DOM 값을 읽어 확인 (예: SVG `text` 목록으로 라벨 겹침 확인).

## 2. 폭·여백
- 카드 안 표는 **카드 폭을 채운다** (`width:100%`, 필요하면 `table-layout:fixed` + 첫 열 폭 지정). `.fit` 은 열이 2~3개인 작은 표에만.
- 카드 오른쪽에 큰 빈 공간이 남으면 실패. 열을 넓히거나 정보를 옆으로 배치한다.
- 같은 종류 카드는 같은 높이·같은 안쪽 여백(`--gap`, 10~16px). 간격 값은 4의 배수.

## 3. 표 가독성
- 숫자 열: 오른쪽 또는 가운데 정렬을 열 전체에서 통일, `font-variant-numeric: tabular-nums`.
- 값과 증감을 한 칸에 넣을 때: **값과 증감을 각자 고정 폭 자리**에 둔다 (예: 칸 안 2열 grid, 값 오른쪽 정렬 · 증감 왼쪽 정렬). "2 -6" 처럼 붙여 쓰지 않는다.
- 증감 표기: `▲3` / `▼3` / 0 이면 표시 안 함. 색 의미는 화면 전체에서 같게 — 늘면 나쁜 항목(결근·지각·조퇴·Reopen 등)은 ▲빨강 ▼초록, 중립 항목(연차·휴가 등)은 회색.
- 열이 많으면 머리글을 묶는다 (예: "근태 이상" / "휴가·휴직"), 묶음 사이 세로 구분선.
- 기준 행·러닝 행처럼 특별한 행은 배지 + 배경으로 구분하고, 표 아래 한 줄로 읽는 법을 적는다.
- 크기 비교가 중요한 표는 칸 배경을 값에 비례해 옅게 칠한다 (`color-mix(in srgb, var(--danger) calc(var(--heat) * 22%), transparent)`).
- 날짜: 주는 "11-15 ~ 11-21" 처럼 범위로. 연도는 머리글이나 부제에 한 번만.

## 4. 차트 (app/core/charts.py, 서버 SVG)
- 축 라벨이 겹치지 않는지 (마지막·기준 라벨이 붙어 있으면 하나 뺀다).
- 데이터 없음 / 0 / 덜 끝난 기간(러닝 주)을 서로 다르게 보이게.
- 평균·목표선은 점선 + 범례 문구.

## 5. 문구·색
- 쉬운 한국어. 숫자는 단위와 비교 대상을 같이 ("전 주 대비 ▲3칸", "평균 대비 +17%").
- 색은 `static/css/tokens.css` 변수만. 새 색이 필요하면 토큰을 먼저 추가.

## 6. 끝내기 전
- `pytest -q` 전부 통과, 렌더 테스트에 바뀐 문구/구조 하나 이상 검사.
- 사용자에게는 무엇이 어떻게 바뀌었는지 + 어느 폭에서 확인했는지 말한다.
