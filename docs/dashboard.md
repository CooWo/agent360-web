# 대시보드 (첫 화면, 이름은 정하는 중)

- 위치: `app/modules/dashboard` (order 5 → 상단 메뉴 맨 앞, `/` 가 여기로 감). 계산 `services/summary.py`, 화면 데이터 `views.py`.
- 범위: 로그인한 사람의 권한 범위(SV = 담당 팀) 전체.
- 칸
  1. 한눈에: 인원(재직·팀·최근 90일 입사) · 근태 최근 28일(결근·지각·조퇴 비율 = 세 상태 칸 / 근무일 칸, 휴무·연차·휴가·휴직 제외) · QA·코칭(올린 파일: 평가 가중 QA 평균, 코칭 Rate = 코칭/평가) · 오늘 할 일(신호·후속 확인)
  2. KPI 최근 4주 vs 직전 4주 + 8주 추이 (담당 전체 Σ분자/Σ분모, 목표는 섹터·테뉴어마다 달라 전체에는 안 씀)
  3. 팀별 비교 (인원 · NPS · SPD · Throughput · Reopen · QA 평균 · 코칭 Rate · 코칭 부족 · 결근·지각·조퇴·연차휴가)
  4. 근태 주차별 (토요일 마감)
  5. 오른쪽: AI 브리핑(팀 이름은 가명) · 먼저 볼 상담사 5명
- 설정: `screens.json` (주 수, 지표, 근태 일수, 신규 입사 기준일).
- 더 넣을 후보: 물량·SL(Capacity 포케스트와 연결), 디트랙터 주간 건수(GDA), 이탈 위험(승인 후), 교육 기수 진행.
